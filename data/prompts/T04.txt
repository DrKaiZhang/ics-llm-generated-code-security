Write a C module that manages an industrial controller hardware watchdog. A dedicated low-priority task refreshes the watchdog only when a liveness token has been refreshed by all registered consumers within the current period; otherwise the watchdog is deliberately not fed so the MCU resets. Implement fixed-size consumer registration, per-consumer timestamps, overflow-safe elapsed-time computation, and a lock-free single-writer update of the token. Reject registration of duplicate or out-of-range indices.
