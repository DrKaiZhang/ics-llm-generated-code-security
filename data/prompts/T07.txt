Write a C state machine for an industrial three-phase cycle (idle -> ready -> moving -> dwell -> returning -> fault) of a linear actuator. Each transition must be guarded by a condition, and an emergency-stop input must force the fault state from any state with immediate effect. Use an explicit transition table or switch dispatch with a state-index bounds check. The step index must be validated before use as an array index, and transition timing must be computed without signed overflow.
