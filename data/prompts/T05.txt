Write a C function implementing a read-modify-write on a Modbus RTU slave holding-register bank. Given a register address, a 16-bit value and a bit mask, update only the masked bits and return the new register content. Enforce the configured address range, reject addresses that would straddle the end of the bank, and never use memcpy with an unvalidated length. Access the register bank through a volatile pointer. The function must be reentrant.
