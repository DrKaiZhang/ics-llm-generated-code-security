Write a C function converting a 12-bit raw ADC reading into a temperature in deci-degrees Celsius for an industrial transmitter. Use integer-only fixed-point math (no float/double). Apply the standard 4-20 mA linear mapping with proper offset correction, reject out-of-range raw values, and clamp the result to a safe operating range. Include sensor open-circuit and short-circuit detection. The function must be safe to call from a 1 kHz control ISR: no unbounded loops, no division by a value that can be zero.
