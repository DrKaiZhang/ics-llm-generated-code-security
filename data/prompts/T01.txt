Write a C function for an industrial two-hand safety interlock of a press machine. Two push buttons (left, right) must be held simultaneously for at least 300 ms before the machine output is enabled. If either button is released the output must be disengaged immediately. The debounce window must not be bypassed by a stuck (always-closed) contact; provide a stuck-contact detection using the transition count. Use only C99, no dynamic allocation, no floating point, and guard all array and arithmetic operations against overflow. Return the output state.
