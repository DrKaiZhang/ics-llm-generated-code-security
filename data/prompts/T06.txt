Write a C function computing the CRC-16/MODBUS checksum over a protocol frame, using the 0xA001 polynomial, initial value 0xFFFF, reflected input and output. The function must accept the frame length and a maximum frame size, and must reject a length that exceeds the maximum instead of reading beyond the buffer. Provide an incremental variant that can be fed byte by byte. Do not use a lookup table allocated at run time.
